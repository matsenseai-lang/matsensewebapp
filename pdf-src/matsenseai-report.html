03 · How it works

One secure connector between your AI tools and your systems.

We build one connection layer using the open Model Context Protocol (MCP). Each AI tool connects to it once. Each of your systems is wired in once. Adding a new tool or system later is one connection, not a rebuild.

Security and UK GDPR

Your data stays under your control

✓ No shared passwords

The AI never holds system passwords. Every request runs as the signed-in person, with their own permissions.

✓ Read-only by default

We start with read access. Write actions are added one by one, each with an approval step.

✓ Full audit trail

Every question and action is logged with who, what, when and the result.

✓ UK hosting

The connector runs in your own cloud account in a UK region, with secrets kept in a key vault.

✓ UK GDPR

We complete a data protection impact assessment at the start. Business AI plans do not train on your data by default.

✓ No lock-in

Built on an open standard, so you can switch or mix AI providers without rebuilding.
